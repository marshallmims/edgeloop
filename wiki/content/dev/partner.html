This is Share Control on 1.1.5. The button changes the page you are on. The toys stay with the browser that paired them. The controller sends commands. It does not pair its own Handy and call that yours. On the live 1.1.4 site the button still opens a popup with two links. That is the Main page.

The page of the person wearing it

The header button is Share Control. It does not open the 1-on-1 and group popup from 1.1.4. The person whose toys are connected sees the devices, whether a controller is connected, the timer, the heart rate and its graph, and what Primary and Secondary are doing.

Play Style, Session Endgame, and Stimulation Intensity leave this page. They are on the controller. Stop on this page still stops the toys. Solo puts those controls back and leaves Share Control. While sharing is on, the header still says Share Control.

The controller link and Copy are on this page. The link ends in ?partner=. The badge counts who is connected. An introduction still goes through PeerJS, loaded from a CDN, so the first visit needs that host reachable. If the script never loads, the link says the library could not be loaded and sharing does not open. After the introduction, the commands go from browser to browser. They are not stored on an EdgeLoop account. There is no EdgeLoop account.

Every message that arrives is checked before it is acted on. A command the page does not recognise is dropped. The heart rate is sent when a reading arrives. The one-second clock still sends the rest of the session.

The controller

The controller gets the regular cockpit. They can start, pause, stop, mark an edge, and force an orgasm. They set the play style, the ending, and the intensity. The device row shows the other person's connections. A controller link opens on Manual Control. EdgeLoop Control is one tap away. Using 1.1.5 is that panel: You or EdgeLoop on each toy, the dots, and Traditional.

Stroke commands stay inside the travel limits already set on the toys. A silent link eases the toys off, and a loop stops if the controller goes quiet. If the controller drops, the toys stop.

The single max, the dual max, the target mode, and the endgame are the wearer's. A controller page does not fill those in from its own saved settings. Edge Training's hold length and edge count, and the pullback percent, are read from the wearer's telemetry.

The controller does not need the heart-rate monitor, and does not need the toys. Those stay on the wearer's machine. The controller needs a browser that can open the link.

A viewer

1.1.5 does not offer a viewer link in the page. The 1.1.4 popup did: a link ending in ?group_sub=, any number of people, the pulse only. A link of that shape still opens a read-only page if you already have one. This build does not mint a new one.

If the link drops

A remote page pings every 5 seconds. A link that has been silent for 20 seconds is dropped. A dropped link is shown as disconnected. It is not left looking connected.

If the wearer's room is gone, because the tab was closed or Share Control was reopened, the partner is told the room was not found and needs a fresh link. An old link does not attach to a new room.
