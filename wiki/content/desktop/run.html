The program is a small server on this computer. It opens EdgeLoop in your browser and stays running in a terminal window. Closing that window stops it. The current program is the 2.0 window. An earlier host is still in the project.

What you need

  • A copy of the EdgeLoop project on Windows, Mac, or Linux.
  • Node.js 22 or newer. node -v should print a version that starts with 22.
  • Chrome or Edge, which is what the page already requires for Bluetooth and for a T-Code cable.

Start it

From the project folder, the 2.0 window is npm run desktop. That is node desktop/host.mjs. It serves http://127.0.0.1:17321/?shell=1#/loop and prints the address. Leave the window open. The page listens only on this computer. The same files without ?shell=1 are the website layout, not the tabs.

The window is one set of tabs. Flipping a tab does not load a new page, so a session keeps running and a video keeps playing. Loop is the cockpit. Video is the player only. Session is duration, guards, voice, and backup. Library is a folder or a network share, and each video is paired with a stroker script and a secondary script. A green dot on Loop means a session is going. A green dot on Video means the picture is playing. Guide, History, and Share sit as icons on that row. The program shows 2.0. The page inside it is the 1.1.5 player, footer 1.1.5.13.

The earlier host is still there:

  • Mac or Linux: sh app/start.sh
  • Windows: app\start.bat
  • Any of the three: npm run app, which is node app/host.mjs

That window prints EdgeLoop app: http://127.0.0.1:8787/ and opens that address. It listens only on this computer. The default port is 8787. EDGELOOP_PORT changes it, if you set that before you start. The Player clock card appears on this host. The same card stays hidden on edgeloop.app and on dev.edgeloop.app, because those sites have no local program behind them.

Stop it

Closing the terminal stops whichever host you started. Quit, on the Player clock card, closes the earlier host. Either one drops a headset or VLC connection that host was holding. The toys are still stopped by Stop in the page, the same as the 1.1.5 player. Quit is the program, not the session.

Building a copy

Two build files live in the project for people packing it themselves. Neither is a download on the wiki.

  • A Flatpak manifest, packaging/flatpak/app.edgeloop.App.yml. It is not a Flathub listing.
  • node packaging/pack-portable.mjs writes zip folders under dist/ that carry their own Node, one for Linux x64 and one for Windows x64. Those zips are not published here.
