The program is a small server on this computer. It opens the EdgeLoop page in your browser and stays running in a terminal window. Closing that window stops it.

What you need

  • A copy of the EdgeLoop project on Windows, Mac, or Linux.
  • Node.js 22 or newer. node -v should print a version that starts with 22.
  • Chrome or Edge, which is what the page already requires for Bluetooth and for a T-Code cable.

Start it

From the project folder:

  • Mac or Linux: sh app/start.sh
  • Windows: app\start.bat
  • Any of the three: node app/host.mjs

The window prints EdgeLoop app: http://127.0.0.1:8787/ and opens that address. Leave the window open while you play. It listens only on this computer, for its own page. The default port is 8787. EDGELOOP_PORT changes it, if you set that before you start.

The Player clock card, the one labeled Player clock, appears only on this page. The same card stays hidden on edgeloop.app and on dev.edgeloop.app, because those sites have no local program behind them.

Stop it

Quit, on the Player clock card, closes the program. Closing the terminal does the same thing. Either one drops the headset or VLC connection. The toys are still stopped by Stop in the page, the same as Dev. Quit is the program, not the session.

Building a copy

Two build files live in the project for people packing it themselves. Neither is a download on the wiki.

  • A Flatpak manifest, packaging/flatpak/app.edgeloop.App.yml. It is not a Flathub listing.
  • node packaging/pack-portable.mjs writes zip folders under dist/ that carry their own Node, one for Linux x64 and one for Windows x64. Those zips are not published here.
