Desktop 2.0 is a side project. It is experimental. It runs EdgeLoop on this computer so a headset, or VLC, can own the video clock. It is not a release, and it is not the live site.

You are reading Desktop. It is still the experimental local app. Main is 1.1.4 on edgeloop.app, footer 1.1.4.31. Dev is 1.1.5 on dev.edgeloop.app, footer 1.1.5.13. The page inside this program is that 1.1.5 player. 2.0 is the name this program shows once it is open. It is not the website footer, and it is not a release.

What it is for

The website cannot follow a headset. HereSphere and DeoVR play the video on the headset and can publish the playhead on the local network. This app connects to that clock, serves the EdgeLoop page on this computer, and loads the funscript whose name matches the video. VLC can stand in, on this same computer, when you do not have a headset.

The app does not choose a speed. The page does, from the heart-rate monitor, the same way the 1.1.5 player does. You still connect a monitor and a toy in the page. The tabbed window is the current program. An earlier host, on port 8787, is still in the project and is the one with the Player clock card.

This computer Run it Node, the 2.0 window, and the earlier host that is still in the project. Video Headset and VLC The timestamp server, the folder of scripts, and Quit. The page The 1.1.5 player Solo, Video Player, and the rest of the cockpit this app opens. Output Connect a toy The Handy, Intiface, T-Code, and the VacuGlide, same as Dev.

What it is not

  • It does not replace edgeloop.app or dev.edgeloop.app. Those stay in the browser.
  • The page listens only on this computer. Another machine cannot open the cockpit. A television link, when you ask for one, is a separate port.
  • It does not upload the video, the script, or the folder.
  • Android is not in this build.
  • There is no published installer. You run it from a copy of the project.
