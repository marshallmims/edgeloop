Desktop 2.0 is a side project. It is experimental. It runs EdgeLoop on this computer so a headset, or VLC, can own the video clock. It is not a release, and it is not the live site.

You are reading Desktop. Main is 1.1.3 on edgeloop.app. Dev is 1.1.4.13 on dev.edgeloop.app. The page this app opens is that Dev player. 2.0 is the name of this local program. It does not appear in the app footer.

What it is for

The website cannot follow a headset. HereSphere and DeoVR play the video on the headset and can publish the playhead on the local network. This app connects to that clock, serves the EdgeLoop page on this computer, and loads the funscript whose name matches the video. VLC can stand in, on this same computer, when you do not have a headset.

The app does not choose a speed. The page does, from the heart-rate monitor, the same way Dev does. The player only supplies the time. You still connect a monitor and a toy in the page.

This computer Run it Node, the start script, and the window you have to leave open. Video Headset and VLC The timestamp server, the folder of scripts, and Quit. The page The Dev player Play Style, the Player, and the rest of the cockpit this app opens. Output Connect a toy The Handy, Intiface, T-Code, and the VacuGlide, same as Dev.

What it is not

  • It does not replace edgeloop.app or dev.edgeloop.app. Those stay in the browser.
  • It listens only on this computer. Another machine on the network cannot open it.
  • It does not upload the video, the script, or the folder.
  • Android is not in this build.
  • There is no published installer. You run it from a copy of the project.
